# 京考备考台 · 昌平区

面向京考备考与昌平选岗的静态网站。首页、50 天计划、行测、申论、模考、职位库、岗位比较、选岗助手、分数情景、竞争矩阵、个人资料和来源审计均可在浏览器中使用。

## 运行

需要 Python 3；工作簿数据转换需要 `openpyxl`。网站前端不依赖外部 CDN，也不要求在线 npm 包：当前环境无法解析 npm registry，因此实现为零运行依赖的静态单页应用。

```bash
./start.sh
```

脚本会生成 `dist/` 静态网站，并在本机启动 HTTP 预览服务。打开终端显示的 `http://127.0.0.1:4172/` 地址；停止服务时按 `Ctrl+C`。首次打开时创建一个本地档案并设置密码。也可运行 `npm run dev`（地址为 `http://127.0.0.1:4173/`）预览源码版。构建前先刷新数据：

```bash
npm run data:refresh
npm run build
```

`dist/index.html` 将样式和应用代码打包在单文件中，公开考试资料位于 `dist/public/data.json`。本机预览请通过 HTTP 服务打开，不使用 `file://`；Web Crypto 需要 HTTPS 或 localhost 安全上下文。

## 公开部署

GitHub Actions 会运行测试并构建网站，只把 `dist/` 上传到 GitHub Pages；原始工作簿、个人浏览器数据和备份不进入发布产物。推送到默认分支后，Pages 部署完成会在仓库的 `github-pages` 环境显示网址。

## 数据与隐私

- `data/raw/study_plan.xlsx` 是原始计划工作簿的本机副本。刷新脚本只读该副本，不会回写原件；该文件由 `.gitignore` 排除，GitHub Pages 构建也不会复制 `data/` 目录。
- `scripts/build_data.py` 将日程、训练清单与模考空表转换为 `public/data.json`，同时合入明确标注来源层级的岗位样例与聚合观察。
- `data/positions_seed.json` 当前包含 2024–2026 年 272 条可追溯候选职位；并非全区全量职位表，逐岗位条件仍待官方职位表逐代码核对。
- `data/districts.json` 保存北京市民政局 2026 行政区划表中的 16 区名称与代码。当前职位库仍只有昌平候选样例；仅在招录单位名命中标准区名或已审阅别名时生成 `districtId`，无法确定的市级单位保持未知。
- 可以在同一浏览器创建多份相互隔离的本地档案。每份档案使用独立密码，通过浏览器 Web Crypto 加密后保存在当前浏览器；网站没有服务器账户，不上传、不跨设备同步。
- 解锁后档案名、个人资料、每日计划修改、学习记录、设置、收藏、比较清单和模考仅在当前页面内存中以明文使用；`localStorage` 仅保存匿名索引和密文。锁定或重载页面后需重新输入密码。忘记密码无法恢复；清理浏览器数据会删除档案。
- 新下载的备份经过加密，恢复时需要原档案密码。旧版 JSON 备份可能含明文；只有主动选择并确认后才会导入，随后保存为当前档案密文。加密备份和本机工作簿不要提交到仓库。
- 已知报名数字保留资格审查口径、观察时间和来源冲突。未知人数为 `null`，不是 0。当前不展示任何录取概率。

## 更新数据

将经核验的新职位或观察补充到 `data/positions_seed.json`、`data/source_registry.json`，再运行 `npm run data:refresh`。不要用职位总量或区级报名快照填充到岗位级记录。

## 当前覆盖限制

数据更新日为 2026-10-08。当前昌平候选样例收录 272 条职位：2024 年 95 岗 / 197 人、2025 年 91 岗 / 177 人、2026 年 86 岗 / 136 人；第三方汇总参照的 2026 年数字为 88 岗 / 138 人，仍有 2 岗 / 2 人缺少已核对的逐岗明细。年度官方职位分母尚未逐代码核实；样例及第三方汇总都不代表全市官方全量。报名观察与岗位进面分样本均按来源和口径单独展示，不把区级报名数字分摊到具体岗位。网站不能替代官方当年公告和职位表，报考前请回到官方原表核验。

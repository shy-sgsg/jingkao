# 功能变更记录

## 已接入的学习功能

- 在“工作台”侧栏和首页增加科学推理入口及当天任务提示。
- 新增四科知识树、讲解页、题库筛选、逐题练习、限时模拟、错题、收藏、学习统计和题源目录。
- 新增可编辑的独立计划任务；只有显式选择科学推理任务类型才出现科学训练配置。
- 计划任务显示已完成题量，按关联会话中的不同题目汇总；未达目标时可续练，增加目标题量会保留旧记录并重新开放任务。
- 将任务、学习记录和会话写入加密档案，并接入备份导出/恢复；旧档案缺少新字段时兼容读取。
- 保留原 50 天学习计划及原有岗位、选岗、模考数据路径。

## 题源和内容更新

- 发布现有 153 道原创练习；本轮原创题增量为 0。
- 收录北京和上海官方大纲例题、广东和上海考生回忆题，以及华图/中公机构材料。
- 2024 年广东回忆资料补入蜡烛制墨、胰岛素两题；新增“激素调节与血糖”讲解。
- 将测试断言更新到当前题库和讲解数量，避免科学页面构建门禁继续被旧期望值阻塞。

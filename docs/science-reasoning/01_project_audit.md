# 项目审查与科学推理模块现状

审查日期：2026-10-09

仓库：`changping-jingkao-dashboard`

## 架构与部署

- 网站使用原生 HTML、CSS 和 JavaScript ES modules，部署为 GitHub Pages 静态站点；没有应用服务器、API 或关系数据库。
- 入口和主界面分别在 `index.html`、`src/app.js`、`src/styles.css`。哈希路由由 `src/app.js` 管理。
- GitHub Actions 在发布前运行 `npm test`，通过后运行 `npm run build` 并部署 `dist/`。测试脚本已设置单线程，避免页面测试同时清理共享构建目录。
- 公开题目、知识目录和来源信息随静态站点发布。个人学习档案保存在浏览器 `localStorage`，写入前使用 Web Crypto 加密；设备间没有同步。

## 现有学习计划与科学推理接入

- 原 50 天学习计划仍由 `public/data.json` 提供；日计划修改和实际记录保存在个人档案既有字段中。
- 科学推理现位于“备考复盘 → 行测能力”页面的子模块卡片，路由为 `#/aptitude/science`；旧 `#/science` 链接继续兼容。常识判断也已预留子模块入口。
- 独立任务保存在 `studyPlanTasks`，学习状态、答题记录、会话、错题、收藏保存在 `scienceStudy`。旧档案缺少这些字段时会补空集合。
- 任务类型由用户显式选择“科学推理”；普通自定义任务不按标题触发科学模块。练习与限时模拟分开记录。
- 学习和答题记录随个人档案备份导出和恢复；公开题库不写入个人数据。

## 当前内容规模

截至本批更新后，知识树有 128 个知识点，其中 77 个已有完整讲解，分布为物理 37、化学 13、生物 14、地理 13。题库共 249 道：153 道既有原创练习、6 道官方大纲例题、76 道考生回忆题和 14 道第三方机构例题/模拟题。本批新增 5 道上海 B 类回忆题，没有增加原创题。

## 约束与回归重点

- 不读取或重新生成旧 50 天复习计划 Excel；不改写 `public/data.json`。
- 不添加后端、数据库或第三方运行时依赖。
- 旧档案、旧备份与已有岗位、选岗、模考数据应保持兼容。
- 计划任务变更不删除历史答题记录；仅有效答题和交卷计算学习进度，手动完成另行标记。
- 官方大纲例题、考生回忆题和机构题分别标记，不将回忆题冒充官方真题。

## 验收边界

仓库代码可用测试和静态构建核验；真实线上版本需在更新提交推送并通过 Pages 工作流后确认。本次未对旧 Excel 数据路径运行构建。浏览器自动化服务当前未提供可操作的浏览器，因此实际桌面、手机页面及截图验收另标为未测试。

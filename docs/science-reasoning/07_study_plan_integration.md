# 学习计划联动

## 任务类型与配置

在学习计划里新增任务时，用户可显式选择“科学推理”。此类型可设置知识学习、专项练习、限时模拟、错题复习或自由学习，并选择学科、专题、知识点、题量、时长和题目筛选条件。普通自定义任务不会因为标题含有“科学推理”而触发联动。

## 实际进度与续练

- 知识学习：用户确认知识点完成后计入；任务进度按已完成的不同知识点汇总。
- 专项练习和错题复习：任务卡显示已完成题量；按关联会话中不同题目的有效提交数计数。重复题目不会重复增加进度。
- 限时模拟：答题草稿可显示为当前进度；只有交卷或到时自动交卷并形成正式答案后才计入已完成题量。
- 未达到目标题量时，可从任务页继续训练；新会话按剩余题量选题，并排除已计入的题目。
- 提高目标题量会保留原历史、重开系统核验完成的任务，并允许继续做未计入题目。手动完成状态仍保留为手动状态。
- 手动完成：保留为手动状态，不伪造答题量或成绩。
- 过期日期不会自动把任务标为完成。

仍在进行的会话可继续作答；已结束会话保留为复盘记录。计划目标改变不清除既有学习历史。任务删除通过归档保留历史数据。

## 入口

- 工作台首页可显示当天待完成的科学推理任务。
- 学习计划页可创建、编辑、完成或归档任务。
- 科学推理任务的“开始”入口带任务 ID 进入科学推理页面，并在会话记录中保留关联。

# 学习计划联动

## 任务类型与配置

在学习计划里新增任务时，用户可显式选择“科学推理”。此类型可设置知识学习、专项练习、限时模拟、错题复习或自由学习，并选择学科、专题、知识点、题量、时长和题目筛选条件。普通自定义任务不会因为标题含有“科学推理”而触发联动。

## 实际进度

- 知识学习：用户确认知识点完成后计入。
- 专项练习：以该任务会话内有效提交的不同题目计数；答完并完成本次练习后更新状态。
- 限时模拟：只在有效交卷或到时自动交卷后形成正式成绩和完成记录。
- 手动完成：保留为手动状态，不伪造答题量或成绩。
- 过期日期不会自动把任务标为完成。

继续训练时沿用原会话记录；计划目标改变不清除既有学习历史。任务删除通过归档保留历史数据。

## 入口

- 工作台首页可显示当天待完成的科学推理任务。
- 学习计划页可创建、编辑、完成或归档任务。
- 科学推理任务的“开始”入口带任务 ID 进入科学推理页面，并在会话记录中保留关联。

# 页面结构与交互

## 入口和页面

左侧导航“工作台 → 科学推理”进入 `#/science`。模块首页显示题源数量、个人答题统计、错题和收藏入口、知识点目录及来源目录。

科学推理内容按学科和专题展开，知识点页提供讲解、学习状态、收藏/待复习标记和配套练习入口。练习按题逐项作答并显示解析；限时模拟使用独立倒计时和答案卡，交卷后显示成绩。错题、统计和题源目录使用同一份个人记录与静态来源信息。

## 计划联动交互

新建或编辑任务时，只有选择“科学推理”类型才显示科学配置。任务卡展示训练方式、知识点/题量、计划时长、优先级和完成状态。首页提示当天任务；从任务卡进入时携带任务 ID。

## 可访问性与小屏

选择项使用原生表单控件；导航以链接呈现，答题动作以按钮呈现；页面状态和题目来源有文字标识。样式文件为窄屏导航与内容区提供响应式规则。当前静态页面测试覆盖哈希路由、基本文案和构建结果；实际桌面及手机截图需浏览器可用后补验。

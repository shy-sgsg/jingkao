# 使用说明

## 打开模块

在“备考复盘 → 行测能力”页面选择“科学推理”卡片；也可直接打开 `#/aptitude/science`。旧链接 `#/science` 仍兼容。行测能力页中的“常识判断”卡片已预留，内容后续补充。

## 学知识点

在模块首页按物理、化学、生物或地理浏览专题和知识点。打开知识点可读原理、生活例子、适用条件和常见误区；学习后可标记学习完成，也可收藏或标记为待复习。尚未写成完整讲解的提纲会显示相应状态。

## 刷题和模拟

选择学科、专题、知识点和题目来源后开始专项练习。练习逐题提交，提交后显示答案与解析；答错题会进入错题记录。限时模拟使用独立倒计时，过程中可修改选项、跳题和查看答题卡，交卷后生成成绩。

来源标签含义：

- **官方大纲例题：** 由官方考试大纲发布的示例，不等同于历年真题。
- **考生回忆题：** 第三方整理的考试回忆，可能与原卷措辞或图表有差异。
- **机构例题/模拟题：** 培训机构发布的练习，不是考试真题。
- **原创练习：** 项目已有的原创练习题。

## 计划联动

在“学习计划”创建任务，任务类型显式选择“科学推理”，再设置学习方式、学科/知识点、题量或时长。任务卡上的“开始”会带着该任务进入训练；训练记录只更新对应任务。普通自定义任务不会触发科学模块。

## 个人数据

科学任务和学习记录保存在当前浏览器的个人加密档案中。需要换设备或重装浏览器时，在档案备份功能中导出并妥善保存 JSON 备份，再在目标设备恢复。恢复前需确认备份结构有效；科学题库本身随网站更新，不属于个人作答数据。

# 个人使用与换设备指南

## 1. 如何打开网站？

打开你平时使用的京考备考台网址。请用浏览器访问网页，不要直接打开本机的 `index.html` 文件。首次进入后，网站会在这台设备创建一个空白本地档案。

在项目目录本机预览时，运行 `./start.sh`，再打开终端显示的 `http://127.0.0.1:4172/` 地址。正式网址以仓库 GitHub Pages 设置页显示的发布地址为准。

## 2. 固定密码是什么？

访问密码固定为 `1234567890123`。电脑和手机都使用同一个密码。网站不提供注册、改密码或多人账号功能。这个密码只是网页入口，不能保护公开仓库里的同步文件。

## 3. 如何在电脑上学习？

用页面导航打开学习计划、科学推理、常识判断、行测、申论和职位查询等页面。答题时按页面提示选择答案；查看练习结果或正式模拟交卷后，可复盘答案与解析。个人资料、计划修改和学习记录默认保存在当前浏览器。

你可以完全不配置 GitHub，也能继续使用网站学习。不同浏览器或设备有各自的本地档案；浏览器数据清理也会删除该设备的档案。需要换设备时，请先手动同步或下载备份。

## 4. 学习记录什么时候保存？

个人资料、职位筛选偏好、学习计划修改、题目答案、模拟答题进度、交卷成绩、岗位收藏和模考记录会在操作后自动加密保存在当前设备。选择练习答案、保存计划修改或提交模拟后，不需要再点额外的“保存”按钮。

本地保存不等于云端同步。网站不会在后台上传，也不会因为网络恢复而自动同步。换设备前要打开“云端同步”并手动完成一次同步；也可以在个人资料页下载加密备份。

## 5. 如何第一次配置 GitHub 授权？

只有需要把本机新增内容上传到 GitHub 的设备才需要 Token。只读取公开云端备份时，可以先不配置 Token。

1. 打开“云端同步”并确认你理解仓库公开的提示。
2. 进入“同步设置”，打开页面里的 fine-grained token 创建链接。
3. 创建 Token 时只选择 `shy-sgsg/jingkao` 仓库，只授予 `Contents: Read and write` 权限。
4. 回到网站，将 Token 粘贴到“GitHub Token”栏并点“安全保存 Token”。

支持设备加密存储时，Token 会用本机密钥加密保存在该浏览器的 IndexedDB 中。若浏览器不支持，页面会提示 Token 仅保存在当前页面内存；刷新或关闭后需重新输入。每台要上传的设备都需单独配置。不要把 Token 发给别人或粘贴到公开代码中。

## 6. 如何手动云同步？

1. 打开“云端同步”。第一次使用时阅读公开仓库提示并点“我已了解，继续”。
2. 点“开始双向同步”。网站会读取云端文件并显示本机新增、云端新增、更新和删除摘要；此时还没有写入。
3. 检查预览。若有冲突，先逐项选择保留本机还是保留云端。
4. 确认预览无误后点“确认合并并同步”。需要上传而本机尚无 Token 时，按提示配置 Token，返回预览后再次确认。
5. 等待“同步完成”提示。网站会在写入后重新读取文件校验，再保存本机合并结果和同步时间。

同步文件位于公开仓库 `shy-sgsg/jingkao` 的 `sync-data` 分支，路径为 `user-data/backup.json`。其中个人资料和学习记录是任何人都能查看的明文 JSON，请不要同步不愿公开的内容。取消预览不会写入云端。

## 7. 如何在手机上恢复记录？

1. 在手机浏览器打开与电脑相同的网站网址，输入固定密码。
2. 打开“云端同步”，如有公开范围提示，阅读后确认。
3. 点“开始双向同步”，查看“云端新增”等预览摘要，再点“确认合并并同步”。如果这次只需把公开云端记录拉到手机，通常不需要 Token；手机上有新内容要上传时，按提示给手机浏览器单独配置 Token。
4. 完成后回到学习计划或答题页面，检查已恢复的记录。

换设备前建议在原设备先同步并确认成功。仅在手机上打开网页不会自动下载云端数据，也不会自动上传手机记录。

## 8. 如何处理同步冲突？

冲突表示同一条记录的同一字段在本机和云端都改过。预览会并排显示“本机”和“云端”的值。点“保留本机”或“保留云端”，逐项处理完后再点“确认合并并同步”。

没有冲突的独立新增会自动合并。若不确定选哪边，先取消预览，回到对应设备检查记录；之后重新读取云端。删除记录会跟随同步，不会因另一台设备还保存旧副本而自动复活。

## 9. 如果 GitHub 不可访问怎么办？

云同步失败不会清除本机学习记录。检查网络、Token 是否有效，以及 Token 是否仅授权 `shy-sgsg/jingkao` 的 `Contents: Read and write`。修复后重新打开同步面板并点“开始双向同步”；应用不会自动重试或自动覆盖本机记录。

若提示文件已被其他操作更新，重新读取云端并检查新的预览，再决定是否确认。GitHub 暂时不可用时仍可继续本地学习，也可以从“个人资料”页下载本地加密备份。

## 10. 如何导出个人学习记录？

打开“个人资料”，在“个人数据加密备份”区域点“下载加密备份”。下载的 JSON 文件经过加密，不包含题库、职位库或 GitHub Token。请把文件保存在安全位置；恢复时需要档案密码 `1234567890123`。

同步到公开仓库的备份是明文数据；加密下载备份和云端同步文件是两种不同格式。请勿把下载的个人备份提交到仓库或公开分享。

## 11. 如何恢复旧数据？

本版本不会自动读取、迁移或合并旧浏览器档案。新设备和首次使用的浏览器从空白档案开始；原浏览器里已有的旧数据保持原样，不会进入新档案或云端。

如你手上另有自己下载的 JSON 备份，可在“个人资料”页点“恢复备份”，主动选择文件，按提示输入备份密码并检查预览，再点确认。恢复会替换当前本地个人记录。旧版未加密 JSON 只有在你主动选择并确认后才会导入；导入前页面会提示文件本身可能含明文。跳过这项操作即可保持新档案为空白。

## 12. 如何查看是否同步成功？

同步成功后会显示“同步完成”结果，并记录“上次确认同步”时间。再次打开“云端同步”面板，可查看本机状态、待同步状态和最近确认时间。若仍有本机新增、云端新增或未处理冲突，先不要把它当成已完成的双向同步；重新读取预览并处理后再确认。

## 手机使用提示

同步面板、状态、Token 设置、预览和结果都可通过页面导航访问。操作时使用页面上的按钮；若内容在小屏幕上显示不完整，可旋转屏幕或调整浏览器缩放。当前工作区没有可用的手机浏览器表面，手机实机触控与横向溢出尚未验证。

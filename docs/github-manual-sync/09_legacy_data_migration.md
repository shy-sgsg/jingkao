# 旧数据迁移决定

**本次不迁移旧数据。** 用户明确要求“旧数据都不要了，不用迁移旧数据”，因此新版本不会自动扫描、读取、转换或合并以前的浏览器档案。

首次输入固定访问密码时，应用创建新的空白固定档案。旧账号索引、旧加密档案和旧版根键原样留在浏览器存储中；程序不删除这些数据，也不把它们复制到新档案或 GitHub。

在不同设备上，首次登录都创建各自的空白档案。要从启用本功能后开始同步，用户需手动读取云端并确认应用合并结果；需要上传时再配置 Token。旧浏览器数据不会因为首次云同步而恢复。

个人资料页仍保留用户主动选择 JSON 备份的恢复功能。它只处理用户明确选中的备份文件，不会读取旧浏览器存储；恢复会替换当前本地个人记录。此独立的备份恢复入口不构成旧浏览器档案迁移。

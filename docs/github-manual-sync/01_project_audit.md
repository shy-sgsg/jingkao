# 项目审查

审查基于当前工作区文件与本地 Git 配置；没有向 GitHub 写入任何内容。

## 项目与部署

- 前端是原生 JavaScript ES modules、HTML 与 CSS，没有运行时 npm 依赖；`scripts/build.mjs` 将网站打包成 `dist/index.html` 单文件，并把公开数据放到 `dist/public/data.json`。
- `origin` 本地配置指向 `git@github.com:shy-sgsg/jingkao.git`，当前本地默认分支为 `main`。此前未能通过 SSH 验证远程状态，因此此处记录的是本地配置，不代表远端状态已实时核验。
- GitHub Actions 由默认分支构建并部署 GitHub Pages，发布内容只取 `dist/`。个人同步备份位于独立的 `sync-data` 分支，不在 Pages 发布路径内。
- 页面通过 hash 路由工作。网站密码是前端访问门，不是服务端认证。

## 本地记录与保存

- 原有本地档案由 `src/data/encryptedStore.js` 加密后存入 `localStorage`，页面会在用户更改后调用保存路径。
- 新版本在同一站点存储空间创建一个由固定密码打开的空白本地档案；它不枚举或读取旧账号，也不导入旧版根键数据。
- 固定档案 ID、解锁状态、学习状态和旧格式导出/导入能力分别由应用与既有存储代码管理。GitHub Token 使用独立 IndexedDB 凭据库，不放在学习档案里。
- 手动同步个人数据涉及个人资料、学习计划、练习与答题、模考、收藏、比较清单、职位筛选偏好、显示设置和入门状态。静态职位数据、题库、临时搜索文字与 Token 不上传。
- 个人资料页保留用户主动下载加密备份和选择备份恢复的能力。旧浏览器档案不会自动迁移；旧版明文 JSON 只能由用户主动选择并确认后恢复。

## 证据边界

可确认的仓库地址、分支和 Actions 行为来自本地 Git 配置及仓库文件；不能据此确认 GitHub 上当前权限、分支是否已存在或 Pages 线上版本。本次实现未创建远端分支，也未上传个人记录。

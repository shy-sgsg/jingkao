# 安全边界与公开范围

- **公开仓库：** `sync-data` 分支和 `user-data/backup.json` 对任何人可见。个人资料与学习记录是明文 JSON；不要上传不愿公开的信息。
- **固定密码：** 随前端代码公开，只是页面入口，不是服务端认证或隐私保护。
- **Token：** 使用 fine-grained PAT，仓库限定为本仓库、Contents 读写。优先设备本地 AES-GCM 加密存储；不能持久化时只存当前页面内存。清除功能可移除此设备保存的 Token。
- **本机档案：** 在浏览器本地加密保存，但固定密码公开，因此不应把它当作强加密边界。
- **确认边界：** 启动同步后可以读取公开云端文件；任何写入和新建同步分支都必须经过用户确认。打开页面或恢复网络不会触发云端访问。
- **历史版本：** Git 分支保留提交历史。覆盖或删除当前 JSON 文件不会清除旧提交中的内容；误上传内容还需按仓库历史处理。

客户端校验和写后回读用于降低格式错误与并发覆盖风险，不会阻止有仓库写权限的人修改公开文件，也不能抵御设备被恶意软件或同源脚本控制。

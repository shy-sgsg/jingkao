# 个人备份格式

`src/data/sync.js` 当前定义 `schemaVersion: 1`。顶层字段为 `schemaVersion`、`backupId`、`updatedAt`、`data` 和 `tombstones`。缺少必需字段、无效记录编号、重复编号或与删除标记冲突时，校验失败并停止同步。`positionPreferences` 是 schema v1 的可选新增字段；较早的 v1 备份没有它时会使用默认筛选值。

`data` 当前包含：

- 个人资料、每日记录、计划覆盖和计划任务；
- 科学推理、常识判断、行测模块的知识进度、会话、答案、错题、收藏及复习卡片记录；
- 行测与申论手动训练记录、模考、职位收藏、比较清单；
- 显示设置与入门状态；
- 职位筛选偏好：各筛选项、职位排序、情景分析年份与范围。临时搜索文字和当前分页不进入备份。

计划、会话、答题和模考记录有稳定 ID（兼容 `id` 并写入 `task_id`、`session_id`、`attempt_id`、`mock_id` 别名）。手动行测/申论记录依据训练区域和项目名称形成内容身份。

备份排除 GitHub Token、设备加密密钥、密码、云同步基线、静态职位数据及题库。删除的可同步记录通过 `tombstones` 保留删除时间，防止旧设备把记录重新带回。

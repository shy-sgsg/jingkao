# 手动同步流程

1. 打开“云端同步”面板并阅读公开数据提示。打开面板、访问页面、导航、普通保存和网络恢复都不会发起 GitHub 请求。
2. 点击“开始双向同步”。客户端读取本机当前档案与可用的远端备份，验证远端 JSON 和 schema，然后以最近一次同步基线、本机和云端执行三方合并。
3. 检查本机新增、云端新增、更新、删除及冲突摘要。没有旧基线的首次同步将本机数据作为初始基线，避免把空默认档案误判成冲突。
4. 每项字段冲突都需选择本机或云端。取消预览不会更改本机学习数据或写云端。
5. 点击“确认合并并同步”才进入写入阶段。首次同步会从 `main` 创建 `sync-data`；已有文件使用读取时的 SHA 更新。写入后再次读取远端并比较备份内容。
6. 只有验证成功后，应用才保存合并后的本机状态、同步基线与时间。若合并结果已等于远端，则无需写入。

如果文件 SHA 已变化或 GitHub 返回冲突，重新读取并检查新预览。网络、授权、权限、限流或格式错误会显示可重试说明，不自动重试、不后台排队，也不自动覆盖本机状态。

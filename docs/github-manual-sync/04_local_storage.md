# 本地保存与旧数据

登录后的个人学习状态继续自动保存在当前设备。现有档案存储实现把状态加密后放入 `localStorage`；固定密码同时用于打开这个本地档案。由于密码公开，这种本地加密不能替代强安全保护。

GitHub 同步基线、上次同步时间和公开提示接受状态保存在本地档案里。Token 不在档案中；它单独保存在 IndexedDB 的加密凭据区。IndexedDB/Web Crypto 不可用或无法可靠保存时，Token 只在当前页面内存中，刷新后需重新输入。

**旧数据不迁移。** 登录流程只查找本功能固定档案 ID；不会读取旧账号索引或旧版根键，也不会删除它们。新档案从默认空状态开始。要继续使用旧数据，用户需自行在原有浏览器中查看旧档案；本功能不自动导入或合并。

## 本机开发与数据更新

前端运行不增加 npm 运行时依赖。职位工作簿是 `.xls`，导入和原表校验需要 Python 及 `xlrd`：

```bash
python3 -m pip install -r scripts/national/requirements.txt
npm run national:import -- --source "/path/to/中央机关及其直属机构2027年度考试录用公务员招考简章.xls"
npm run national:check -- --source "/path/to/中央机关及其直属机构2027年度考试录用公务员招考简章.xls"
```

默认读取项目同级 `国考/` 目录下的源文件；也可用 `--source` 指定路径。导入会重写 `public/national/positions-2027.json`、`public/national/metadata-2027.json` 和 `research/national/2027_data_audit.md`。先确认导入统计和来源，再运行校验；校验会逐条重读源表并比较完整输出。公开元数据和审计报告只保存源文件名，不保存本机绝对路径。

本脚本面向 2027 职位表，固定输出名、年度和数据模型；未来年度不是只替换 `.xls` 文件名即可，需要先更新导入器的年度 / 字段配置、页面数据加载路径和相应测试，再生成对应版本数据并审计。

前端构建与测试：

```bash
npm run build
npm test
```

GitHub Pages 沿用仓库现有工作流：推送默认分支后，工作流运行测试、构建 `dist/` 并部署。构建把国考数据复制到 `dist/public/national/`，并保持相对部署路径可用。

# 2027 国考职位工具使用手册

## 打开工具

在工作台左侧导航选择“2027 国考职位”。进入后默认显示职位筛选；国考职位文件只在打开国考模块时按需加载。顶部标签可切换“职位筛选”“数据概览”“我的收藏”和“并排比较”。北京京考的职位、筛选和比较仍在独立的京考入口中。

本地预览可在项目目录运行：

```bash
npm run build
python3 -m http.server 4172 --directory dist --bind 127.0.0.1
```

然后打开 `http://127.0.0.1:4172/`。也可运行 `npm run dev` 查看源码版。通过 `./start.sh` 启动原项目提供的预览流程也可以使用。

## 查找职位

- 职位 / 单位 / 地点关键词会搜索职位名称、招录部门、用人司局、职位代码、工作地点及职位条件原文。专业条件的文本检索另有“专业原文检索”字段；命中原文不等于专业符合。文本和人数输入会在停止输入后自动更新。
- 地区字段依据职位表“工作地点”，支持省份、城市、区县多选。选择省份后城市选项会收窄到所选省份；选择城市后区县选项会收窄到所选城市。更改上级地区会清除下级选择。同一地点字段中的多个值按“或”匹配，不同筛选维度之间按“且”匹配；系统不会按招录机关地址猜测工作地点。
- “具体招录部门”可多选；“部门 / 用人司局搜索”支持多个关键词，以逗号、中文逗号或顿号分隔，命中招录部门、用人司局或部门代码中的任一项即可。
- “机关类型”、学历原文、学位原文、政治面貌原文、基层工作年限、考试类别和资格初步核对可多选。同一字段选择多个值按“或”处理。
- 可设置招录人数上下限、面试专业能力测试、备注 / 项目条件、只看专业不限、快速筛选初步符合、排除仅限男性报考岗位，以及排除资格或特殊条件待核验项，并按招录人数升 / 降序、部门、地点或职位代码排序。快捷条件还可只看招录 2 人及以上的职位，或要求关键条件字段完整；筛选区会显示可能因此隐藏的待人工核验数量。
- 点击“公共管理专业一键筛选”可按职位专业原文和专业代码筛选管理学、公共管理及土地资源管理方向，包含 `12`、`1204`、`1252`、`120405` 等代码。个人资料中的专业属于这一范围时，相关文字和代码也会计入专业初步匹配；可再次点击取消。
- 性别排除检查备注和其他职位要求原文；“限男性”及要求字段中单独列出的男性 / 男生会排除，“男性优先”、限女性和男女均可不会排除。查看职位详情仍可核对完整原文。
- 结果区显示职位总量、地区内数量和资格阶段计数；每个启用条件都有可单独移除的标签。
- 使用“设置表格列”调整结果表显示字段。专业匹配、综合资格、学历和备注提示默认可见；选择会保存在国考工作区。
- 筛选变更后会更新数量和结果。结果按每页 30 个职位展示；打开“筛选条件”可折叠筛选面板。桌面端以带字段标题的表格展示职位；手机端每行会重排成卡片，筛选面板收在抽屉中。
- 展开职位详情可查看资格核对、全部原文并填写个人备注。
- 使用“清除条件”恢复默认筛选。保存方案会保存当前筛选，可从已保存方案一键恢复、重命名或删除。

## 查看资格初步核对

到“个人资料”补充最高学历、已取得学位、本科 / 研究生专业及对应代码、政治面貌、毕业身份、毕业年份、基层工作年限和服务基层项目资格。专业代码请按本人毕业材料和适用目录核实填写；系统不会从旧的“专业”字段推断学历阶段或专业代码。

职位详情会并列显示职位要求、个人档案值和逐项判断依据。专业可按明确目录代码及专业名称核对；管理学类、公共管理、行政管理、公共事业管理、土地资源管理及 `12` 开头的相关专业范围，若与个人资料对应，也计为初步匹配。其他含“相关专业”等且无法对应的表述仍需人工核验。学历判断会区分“仅限本科”和“本科及以上”等明确层级。职位学位要求为“与最高学历相对应的学位”时，该项按符合处理。政治面貌、基层年限、毕业身份、服务基层项目及其他非标准限制，条件不足或不能可靠解释时显示待核验 / 资料不完整。

“快速筛选：只看初步符合岗位”会显示专业初步匹配、已填写条件无明确不符合且没有缺失资料的职位；其他仍需人工核对的条件会保留在详情中，不会单独阻止其进入初步符合结果。明确不符合或资料缺失仍会分别显示。该状态不代表招录机关的最终资格审查；逐条核对职位详情中的全部职位表原文，并以官方公告及招录机关答复为准。

## 收藏、备注和比较

- 在职位结果中点“收藏”加入国考收藏。收藏页可按职位 / 部门文字搜索，并按普通、优先核对、继续关注筛选。
- 展开职位详情可保存不超过 2,000 字的个人备注和优先级。备注随收藏保存在个人档案中。
- 点“加入比较”把职位放入国考比较清单。最多同时比较 6 个国考职位；在比较页可移除、上下调整顺序、只看差异项或导出比较 CSV。职位身份带有 `national:2027:` 前缀，京考清单不会与国考清单混用。

## 导出与保存

“导出当前结果 CSV”按页面当前的全部筛选和排序导出；收藏页和比较页也各有对应导出。文件为带 UTF-8 BOM 的 Excel 兼容 CSV，不是 `.xlsx`。导出包含职位表字段、资格初步核对摘要和个人备注；CSV 单元格会处理公式前缀，避免内容被电子表格当成公式执行。

筛选、收藏、比较和备注进入已有的本机加密档案，并可通过原有加密备份和手动同步机制保存 / 恢复。国考工作区独立存储。默认不会自动同步；手动同步前请留意现有同步流程会将所选档案字段写入公开仓库的说明。

## 数据边界

目前收录用户提供的 2027 `.xls` 职位表：19,426 个职位、计划招录 35,691 人。报名人数、资格审查人数、竞争比和进面分均未虚构，未知值为空。职位详情保留 27 个原始字段；专业解析覆盖有限，大量规则需人工核对。完整来源、计数、缺失和解析情况见 [`2027_data_audit.md`](../../research/national/2027_data_audit.md)。本机源文件尚未与官方附件做字节级哈希比对。

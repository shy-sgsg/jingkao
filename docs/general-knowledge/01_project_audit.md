# 常识判断项目审计

审计日期：2026-10-09
审计范围：现有京考网站、行测能力页、科学推理、学习计划、个人数据与备份。

## 当前架构

- 网站由原生 HTML、CSS 和 JavaScript ES modules 构成，`scripts/build.mjs` 将其打包为无外部运行时依赖的静态站点，部署目标为 GitHub Pages。
- `src/app.js` 负责哈希路由、页面渲染、学习计划交互和本地档案读写；项目没有应用服务器或数据库。
- 个人数据通过 `src/data/encryptedStore.js` 保存到当前加密账户；`src/data/backup.js` 负责备份结构校验与恢复。
- 行测题量和训练摘要来自 `dataset.aptitude` 与 `storage.aptitudeLogs`。科学推理的答题记录单独保存在 `storage.scienceStudy`。

## 可复用能力

- 通用行测手动记录、正确率与题量汇总：`renderAptitudeRecords()`、`summarizeAptitudeItems()`、`combineAptitudeSummary()`。
- 可扩展的知识点状态、练习/考试会话、错题和统计实现：`src/science/persistence.js`、`src/science/sessions.js`、`src/science/questions.js`。它们当前均以科学推理状态为输入，需通过显式模块隔离后适配。
- 计划任务稳定 ID、归档、完成来源和进度核验：`src/science/planTasks.js`。
- 页面组件、选项按钮、倒计时显示、结果页、移动端样式以及加密档案和备份通道。

不复制整套科学推理目录，也不让常识答题修改 `scienceStudy`。新记录使用 `moduleId: 'general_knowledge'`，题目、统计、错题和会话各自隔离。

## 数据调整、兼容和回滚

- 在现有加密档案中新增可选 `generalKnowledgeStudy` 字段。读取旧档案时以空集合补齐；不修改已有 `scienceStudy`、手动成绩或计划历史。
- 新增题目、知识点和来源作为静态公开内容；个人答题、考试、错题、收藏、卡片复习和常识学习任务进度保存在当前用户档案。
- 备份新增字段采用“缺省兼容、严格校验新字段”的方式；导入前先完成结构校验，避免覆盖科学推理数据。
- 回滚代码时，旧代码忽略新增档案字段；恢复功能后原字段仍可读取。若发现数据格式问题，可从导入前导出的个人 JSON 备份恢复。

## 可能影响与保护措施

- 行测总览需将常识手动记录和常识站内答题以有效答题数加权合并；两种记录同时存在时不能重复计数。
- 学习计划任务需要常识专属配置、跳转和回写；不得依靠标题文本判断模块类型。
- 法律政策和时政题需标注核验日期、适用地区和来源；内容过期时应停用或明确提示，不能默认为仍然有效。
- 题源按可公开核实的官方真题/例题优先，其次为允许展示的第三方模拟题；回忆题明确注明非官方，原创题仅用于现有来源无法覆盖的考点。版权状态不满足展示条件的材料只记来源索引。

## 当前待补

1. 知识点提纲和完整讲解数量不等：215 个知识点仍是提纲，不会计入已学完。
2. 当前 7 道已发布题不足以覆盖 231 个知识点；`docs/question-collection/knowledge-priority.csv` 中的候选讲解和题目摘要仍需逐项核对，不能当成已发布题面。
3. 法律政策和时政题持续核对现行版本、地区适用范围、答案依据和来源日期；第三方题面须先确认展示授权。
4. 内容索引、真题题面与站内已发布题量分开统计；索引摘要不进入练习、错题或模考。

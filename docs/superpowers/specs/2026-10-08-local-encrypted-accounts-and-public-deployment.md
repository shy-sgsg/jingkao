# 本地加密账户与 GitHub Pages 发布设计

日期：2026-10-08  
状态：历史方案；2026-10-09 起由 [GitHub 手动同步验收说明](../../github-manual-sync/13_final_acceptance.md) 取代其账户、数据迁移和“不上传 / 不跨设备同步”行为要求。静态 Pages 发布边界仍适用。

## 目标与边界

将网站从单一浏览器记录升级为同一浏览器内可切换的独立本地账户；个人记录以密码加密后留在当前浏览器。网站发布到 GitHub Pages 时只含网站代码和经过审查的公开考试研究资料，不发布任何人的本地记录或原始复习计划工作簿。

本方案不是服务端账号系统：不注册、不联网认证、不上传、不跨设备同步。所谓“账户”是当前浏览器源下的本地加密档案，不是可跨设备登录的身份。密码遗失后数据及其备份均无法找回。

## 用户可见行为

- 首次访问显示账户创建、既有数据迁移或解锁入口；创建账户时设置本地档案名和密码。多个账户互相隔离，用户可新增、锁定并切换档案。
- 解锁成功后才载入该档案的资料、计划修改、训练日志、模考、收藏、比较清单、引导状态和显示设置；公共职位数据不属于账户数据。
- 锁定或切换账户时，应用切回锁屏并清除其持有的当前明文状态引用和密钥引用。应用重载后默认要求重新解锁。此举不保证 JavaScript 引擎立即擦除内存。
- 密码不保存在浏览器。错误密码与损坏数据显示通用解锁失败提示；不提供密码重置或恢复密钥。
- 账户索引仅显示匿名序号；档案名放在密文中，解锁后显示，避免把个人姓名写入未加密索引。
- 现有单用户明文状态在用户选择迁移并设置密码后，先加密、写入并解密回读校验；只有校验成功才删除旧明文键。迁移失败时保留旧数据并停止，不静默覆盖。
- 既有未加密备份仍可由用户主动选取后导入，先预览和确认，再写入当前档案的加密存储。新的备份导出使用现有档案密钥导出加密信封；恢复需要该档案密码，不生成明文个人数据文件。

## 本地存储与密码学

- 每个档案使用独立随机 ID、随机盐和随机 AES-GCM 初始向量；信封包含版本、密码派生算法参数、盐、IV 和密文，不含密码或明文档案名/用户状态。
- 在 HTTPS 的 GitHub Pages 与 localhost 安全上下文中使用内建 Web Crypto：PBKDF2-HMAC-SHA-256（600,000 次）派生不可导出的 256-bit AES-GCM 密钥。盐为 16 字节，IV 为每次加密新生成的 12 字节。该工作因子采用 OWASP 当前 PBKDF2-SHA-256 建议；Web Crypto 的 AES-GCM 提供认证加密。
- 密钥只在当前解锁会话内存中保留；持久化写入经串行队列处理，避免较慢的加密造成写入乱序或丢失。UI 的“已保存”状态只在加密信封写入成功后出现。
- 不新增运行时依赖、不使用 CDN、不向外部端点发送个人数据。浏览器存储空间不足、Web Crypto 不可用或写入失败时，明确报告失败，不退回明文保存。

## 发布边界与威胁说明

- GitHub Pages 发布的是静态网站；Pages 不承载用户账户数据库。应用只请求自身的公开职位数据文件，不发送个人字段、事件分析或账户标识。
- 公开构建必须排除 `data/raw/study_plan.xlsx`、原始个人工作簿、浏览器存储导出、备份、临时文件、密钥/凭据；发布前审查将要推送的完整文件清单和生成产物。
- 加密用于保护浏览器持久化数据免于直接明文读取，并非完整匿名或绝对安全保证：弱密码可被离线猜测；用户解锁期间页面、恶意扩展、同一设备上的恶意程序或被篡改的网站代码仍可能读取数据。清理浏览器存储会删除本地档案；只有保管好的加密备份可用于恢复。
- 公开源代码和静态职位数据不含用户档案。发布流程不复制浏览器数据或用户工作簿；GitHub Pages 必须由静态构建产物部署。

## 验收

1. 创建两个不同密码的档案，各自保存不同资料；锁定/重载后必须再次解锁，错误密码不能得到任何明文数据；解锁一个档案不会显示另一个档案的数据。
2. 检查浏览器持久化信封不含档案名、专业、模考分数或计划文字；个人字段只存在于加密状态和解锁后的运行内存。
3. 迁移成功后旧单用户明文键不存在，密文回读等于迁移前状态；错误密码、写入失败、回读失败时旧键仍保留。
4. 本地编辑按加密完成顺序保存；锁定后不再呈现个人信息。新备份为密文；旧备份仅在用户选择并确认后导入且落盘为密文。
5. 生产构建和发布清单中没有个人档案、备份、原始 Excel、密钥或凭据；网络请求不包含用户数据。
6. 保留现有 UI、数据和功能回归测试；真实浏览器验收账户创建、迁移、切换、锁定及错误密码路径。

## 依据

- [OWASP Password Storage Cheat Sheet](https://cheatsheetseries.owasp.org/cheatsheets/Password_Storage_Cheat_Sheet.html)：PBKDF2-HMAC-SHA-256 参数参考。
- [W3C Web Cryptography API](https://www.w3.org/TR/WebCryptoAPI/) 与 [MDN SubtleCrypto.encrypt](https://developer.mozilla.org/en-US/docs/Web/API/SubtleCrypto/encrypt)：浏览器密码派生、AES-GCM、HTTPS 安全上下文和异步操作依据。
- 用户已确认：同浏览器多档案、独立本地密码、加密保存、密码遗失不可恢复、不上传、不跨设备同步；公开站只发布已审查的网站和公开资料。

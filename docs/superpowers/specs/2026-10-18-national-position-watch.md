# 国考岗位监控模块规格

## 目标

在现有 2027 国考职位工作区中增加“岗位监控”视图，将用户指定的 65 个职位加入收藏，支持按城市和应届要求筛选，并通过手动导入职位级报名快照来比较岗位竞争情况。

## 当前实现约束

- 网站是静态单页应用，没有后端、数据库或定时任务。
- 职位身份使用 `departmentCode + positionCode`；职位代码单独不保证唯一。站内 `position.id` 已按复合身份生成。
- 现有收藏位于 `nationalWorkspace.favorites`，字段包括 `positionId`、`addedAt`、`note` 和 `priority`。批量导入必须保留已存在的收藏备注、优先级和收藏时间。
- 职位原始字段包含 `freshGraduateRaw` 和 `remarkRaw`；资格初核逻辑可用于显示个人匹配状态，但不能替代人工核对职位原文。
- 本机账户状态加密保存。现有 GitHub 手动同步文件位于公开仓库，个人数据以明文 JSON 保存。用户明确授权将岗位收藏和报名快照写入现有 `sync-data` 分支，因此它们使用已有手动同步；不得把个性化清单嵌入公开职位数据、静态网站资源或代码。

## 页面与交互

- 在国考工作区增加“岗位监控”标签，并保留现有“职位筛选、数据概览、我的收藏、并排比较”功能。
- 岗位监控展示收藏职位表格，字段为：城市、招录部门、用人司局、职位名称/代码、计划招录、最新报名人数、最新资格审查通过人数、报名人数/计划招录、过审人数/计划招录、来源更新时间、数据采集时间、导入时间和来源链接。
- 竞争比明确采用两种口径：`报名人数 ÷ 计划招录人数` 与 `过审人数 ÷ 计划招录人数`。两种口径都可排序；计划招录或计数未知时对应值留空。
- 提供关键词、工作城市、应届要求和现有收藏优先级筛选。应届筛选基于 `freshGraduateRaw` 与 `remarkRaw` 分类为“职位原文明确要求应届”“原文未明确提及应届限制”“待人工核验”；不得把“原文未提及”标成“不限”。当前 65 个岗位中，19 个原文明示应届要求，46 个原文没有应届字样。同时显示现有个人资格初核结果；系统不得仅凭“应届可报”推断职位适合用户。
- 无匹配收藏时显示空状态。表格提供来源链接和最新导入时间；没有来源更新时间的记录显示“来源未标注更新时间”。

## 首批收藏和数据导入

- 首批 65 个岗位按复合身份与职位库精确匹配，批量加入现有收藏。已存在的收藏只补齐岗位监控标记，不覆盖 `addedAt`、备注或优先级。
- 首批岗位清单和当前数据生成一个 CSV 导入文件，放在 `京考` Git 仓库之外；仓库中不包含这 65 个复合身份列表，也不内嵌这份个性化清单。
- 首批数据使用华图职位表当前可见数值；其全国汇总页标注更新时间为 2026-10-17 17:32。职位详情有明确更新时间时记录该时间；未明确显示时保持空白，不把全国汇总时间当成已核实的逐岗时间。
- 页面提供 CSV 文件选择、导入预览和确认。CSV 列为：`department_code`、`position_code`、`applications`、`qualified`、`source_name`、`source_url`、`source_updated_at`、`observed_at`。计数可留空表示未知；`0` 表示来源明确报告为零。来源更新时间可留空；`observed_at` 记录这组数据被查阅/采集的时间；导入时间由应用记录，三者分开保存和展示。
- 预览列出新增收藏、已存在收藏、有效快照行、重复键、未知职位和格式错误。未知职位、重复复合键或无效计数会阻止提交，并指出对应行；确认后一次性写入，不做部分导入。
- 导入只新增或更新文件中出现的岗位，不会取消未出现岗位的收藏，也不会清空未出现岗位的现有快照。相同岗位再次导入时更新其当前快照，空计数按未知保存，不保留成旧值，也不改成零。
- 快照按职位保存报名数、过审数、来源名称/链接、来源更新时间、数据采集时间和本机导入时间。页面只展示每个职位最新快照；本次不做报名趋势图或历史对比。

## 本机隐私与同步

- 监控数据保存在本机加密账户中。首批 CSV 位于代码仓库外，不通过静态网站公开。
- 岗位收藏和监控快照进入现有 GitHub 手动同步 JSON；同步投影会去掉设备内部使用的 `localOnly` 标记。云端同步文件是明文，岗位收藏与快照会随现有个人数据一同写入 `sync-data` 分支。
- 监控筛选文字、城市、应届分类、优先级和排序仍保存在本机；加密备份保留完整的岗位监控工作区。

## 验收标准

1. 首批 65 行全部按部门代码和职位代码匹配到站内职位；重复导入不会增加重复收藏。
2. 批量导入保留既有收藏的 `addedAt`、备注和优先级。
3. 城市、应届要求、优先级和关键词筛选可组合使用；个人资格初核标签与应届原文分类不混为一谈，也不把原文未提及解释为不限。
4. 报名数、过审数、两种每名额比例、来源更新时间、数据采集时间和导入时间正确呈现；未知值为空，零值显示为 `0`。
5. CSV 有效行经预览确认后才写入；重复身份、未知职位或无效数据不会造成部分写入。
6. 后续导入更新对应职位的当前快照，不移除未出现在文件中的收藏或快照。
7. 手动同步会保留岗位收藏和监控快照，且不写入 `localOnly` 设备标记；监控筛选状态仍保存在本机。
8. 项目不新增自动抓取、定时更新、后端服务或运行时依赖。

## 本次不包含

- 自动抓取华图或其他网站的数据；用户通过 CSV 手动更新。
- 在公开职位数据、代码或页面初始资源中公开用户的 65 个目标职位。
- 对报考资格作自动定论；职位要求和个人材料仍需用户核对。
- 招录单位官方接口接入、趋势图、提醒推送或新的云端存储。

# 国考收藏岗位在线监控刷新规格

## 目标

在岗位监控页提供一个按钮，从华图公开的 2027 国考职位统计页获取最新报名人数和合格人数，并更新本机收藏岗位的监控快照。

## 已批准行为

- 来源采用华图 2027 职位统计页；记录来源名称、来源页面、来源更新时间和采集时间。
- 通过 GitHub `repository_dispatch` 触发仓库 Actions，在服务端抓取网页并写入 `sync-data/monitoring/national-2027.json`。
- 按钮事件只携带随机请求编号，不携带职位代码、收藏清单、备注或其他账户数据。
- 页面从公开快照读取后，在本机按职位代码匹配收藏岗位；显示匹配、未匹配和数据更新时间供用户确认。
- 确认后仅合并匹配的监控快照到本机加密档案；不新增、删除或改写收藏记录。
- 若抓取失败、结构变化或职位覆盖不完整，Action 不覆盖上一份有效快照；页面保留现有监控数据并展示错误。
- 保留现有 CSV 导入和 sync-data 个人备份读取功能。

## 数据与抓取

- 读取华图省级页面及其下属城市、单位页面中的职位表。
- 以职位代码作为公开来源记录的主键。相同职位代码若出现冲突数据，不纳入快照。
- 省级职位总数用于完整性校验；只有抓取到的唯一职位数达到页面声明的总量，才发布新快照。
- 报名人数和合格人数允许为 `null` 表示来源未知；数字 `0` 保留为明确的零。
- 公开快照只存年份、请求编号、采集时间、来源更新时间、唯一职位总数和岗位级统计值，不包含用户数据。

## 失败处理

- 没有配置有仓库 Contents 写权限的 GitHub Token 时，提示用户先配置现有同步令牌。
- 如果 Actions 在等待期限内未发布对应请求编号的快照，提示刷新超时，不修改本机数据。
- 没有匹配到收藏岗位时仍展示来源时间和未匹配数量，不覆盖本机数据。

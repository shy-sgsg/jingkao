# 行测板块统一学习架构

## 目标

让行测总览中的七个板块使用一致的学习、练习、统计和计划入口：政治理论、常识判断、言语、数量关系、判断推理、科学推理、资料分析。科学推理与常识判断作为已有完整模块接入统一模块契约；其他五个模块先具备同一运行入口和可扩展题库接口，当前不收集或新增题目。

## 当前状态

- 科学推理和常识判断已有独立知识目录、练习/限时模拟、错题或收藏、统计及计划联动。
- 政治理论、言语、数量关系、判断推理和资料分析只有手动训练记录及占位内容卡片。
- 学习计划的训练配置和进度核验目前仅接入科学推理与常识判断；政治理论还未作为独立计划任务类型出现。
- 行测总览、旧模考模块表和各训练页面使用了多份模块名称定义，存在重复维护。

## 方案

采用一个行测模块注册表和一套公共学习页面/任务接入契约。保留科学推理和常识判断目前使用的个人档案字段及路由，通过适配器接入；其余模块使用独立、可空的内容提供器和学习状态。这样既可统一入口和交互，也不需要搬动已保存的科学推理或常识判断历史。

不采用逐个复制科学推理和常识判断页面的方式，以免同一计划、统计和答题规则继续分叉；也不在本次重写两套已有模块的数据格式。

## 模块契约

模块注册项包含稳定 `id`、显示名称、图标、提示文本、旧训练记录映射、知识目录提供器、讲解提供器、已发布题库提供器、学习状态适配器和计划任务适配器。行测总览、板块路由、计划类型选择和训练记录列表均从注册项生成。

题库接口按模块和筛选条件返回可练习题目，默认只返回已发布且通过本模块校验的条目。题目保持现有字段约定，包括稳定题目 ID、知识点 ID、题干、选项、正确选项、解析、题源和发布状态。科学推理与常识判断由已有题库适配器供数；政治理论、言语、数量关系、判断推理和资料分析在本次注册为空题库。题库为空时页面应显示明确的待接入状态，不能创建空会话或伪造练习记录。

知识目录和讲解使用相同的可用性约定：内容提供器可返回目录、讲解或空集合。空目录显示待接入状态；不能将占位文本标成已发布讲解或已完成学习。

## 页面与学习数据

所有模块使用一致的页面骨架：模块概览、学习/练习入口、错题与收藏状态、统计、手动训练记录和计划入口。已有模块的专用知识页面、训练页和统计继续由各自适配器呈现，但使用注册表提供的名称、路由和统计汇总规则。

科学推理与常识判断继续使用 `scienceStudy` 和 `generalKnowledgeStudy`。新增模块状态按稳定模块 ID 隔离保存；会话、答案、错题和收藏必须保留所属 `moduleId`，不同模块相同的题目 ID 不得互相污染。旧档案缺少新增模块状态时规范化为空集合；备份导入/导出须往返保留这些状态。手动录入与站内答题按有效题量汇总，不能把相同站内作答再次当作手动记录。

## 学习计划

计划任务类型覆盖七个行测模块，并从模块注册表生成选项、直达路由和训练入口。所有模块共用训练方式、知识点/专题筛选、目标题量、限时和来源/难度筛选字段；具体可用字段由模块适配器校验。任务进度只依据本模块、关联该计划任务且有效的学习记录核验。空题库模块可创建计划并查看配置，但在题库接入前不能开始练习或自动核验题量完成。

现有 `scienceConfig`、`generalKnowledgeConfig` 和任务历史保持可读；新模块配置使用模块 ID 归属，更新任务类型时清除不匹配的配置而保留实际学习历史。旧任务无需迁移。

## 路由与兼容性

新增统一模块路由，并保留 `#/aptitude/science`、`#/aptitude/general-knowledge` 现有链接。旧的 `#/aptitude/module/<id>` 链接继续可解析，逐步指向注册表驱动的模块页。手动记录数据键和值不改动；首页、导航、模考筛选和计划提示中重复声明的行测模块列表改用同一注册表。

## 验证

- 注册表恰含上述七个板块；所有路由、总览卡片和计划任务类型都能定位到对应注册项。
- 科学推理与常识判断旧档案/备份状态通过适配器后保持不变，模块间记录隔离。
- 空题库模块显示待接入状态，启动练习被阻止且不新增会话；使用测试专用合成题验证公共会话、答题和计划进度接口，不把合成题加入发布数据。
- 计划配置可保存、编辑、直达正确模块；进度只读取同模块、同任务的有效记录，跨模块和重复答题不累计。
- 原有手动记录、科学推理、常识判断、备份、模考和路由测试保持通过；静态构建可运行。

## 范围边界

本次只做板块架构、页面/计划/状态接入及相关验证。不新增或搜索题目，不编写新的知识讲解，不重做申论或全站模考系统，也不改变选岗和用户既有个人记录。

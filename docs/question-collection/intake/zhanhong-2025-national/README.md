# 展鸿 2025 国考行测模拟卷

来源：展鸿 / 32 学苑公开 PDF，含副省级、地市级、行政执法类三套行测题本及同卷答案解析。用户确认已取得转载授权。

题面和选项按来源原文录入，原题号、卷别及模块范围保留；答案与解析逐题核对。PDF文字层未保留的图形、图表和公式解析通过原卷页面截图补足，解析配图只在答题后显示。共用材料按题组共享。

- `publisher-original-pack.pdf`：原卷。
- `publisher-text-extraction.txt`：原卷文本提取。
- `questions-1.json` 至 `questions-3.json`：题面与选项，不含答案。
- `answers-1.json` 至 `answers-3.json`：答案键。
- `answer-explanations-1.json` 至 `answer-explanations-3.json`：原文解析提取及无法文本提取部分的原卷截图引用。
- `shared-stimuli.json`：共用材料及原图引用。
- `pack-manifest.json`：题量、模块边界与发布状态。
- 网站图形与解析图片位于 `public/assets/question-bank/zhanhong-2025-national/`。

# 行测题目搜集暂存区

本目录保存题源索引和少量题目摘要，供各模块接口完成后统一导入。当前只整理资料，不改 `src/` 题库或模考接口，也不新增原创题。

## 收录优先级

1. 北京历年考生回忆卷与官方大纲例题。北京官方公告可核年度、考试安排和大纲；本次检索到的实际题面均由第三方或考生回忆提供，不能标作官方原卷。
2. 其他省份、国考历年回忆卷。优先保留多卷种、近年和有逐题答案来源的整卷。
3. 第三方机构模拟卷。记录发布机构、卷种和答案入口；模拟题与真题分开。
4. 原创题。本批没有新增原创题。

## 文件

- `paper-index.csv`：整卷和模拟卷索引。每行是一套卷，或明确标为“系列”的批次。题量取自来源页目录或卷面；未知时留空。
- `question-index.csv`：题目摘要与来源映射索引，保留原卷号、模块归属、共同材料/图形依赖和答案核验状态。摘要不复制整段题干。
- `source-catalog.csv`：官方公告、大纲、题库目录、回忆 PDF 和机构模拟入口。
- `pending-candidates.csv`：需要补证、题面缺失、版本矛盾或只能在客户端/会员区访问的来源。
- `knowledge-priority.csv`：常识判断优先知识点讲解草稿、对应练习题索引和官方参考来源；未核验题目仅作为候选。
- `science-knowledge-practice-map.csv`：现有科学推理知识点与已发布练习题的对应清单，不复制应用内课程或题目内容。

## 后续导入约定

导入时沿用 `paper_id`、`original_question_no`、`section_order`、`module` 和 `shared_stimulus_id`。整套模考按原卷顺序读取同一 `paper_id`；随机组卷按模块抽取单题，并将共用材料的一组题作为整体抽取。图形、表格、长篇材料等题目只有在题面资源齐全时才进入可练题库。

题面只有外部来源、没有明确授权的，暂存来源链接、题号、短摘要和核验状态，不把第三方整卷全文复制进仓库。考生回忆题始终标为回忆资料；官方大纲例题与实际考试题分开。

## 目前搜集概况

当前目录有 93 条整卷、卷型、系列或候选记录，37 个题源目录项，10 条待核来源；逐题索引有 74 条摘要/来源映射。逐题摘要覆盖政治理论、常识判断、言语理解、数量关系、判断推理、资料分析，并映射现有科学推理题源。北京 2023 回忆 PDF 本批增加 14 道常识题摘要，并补入北京 2026 官方大纲常识判断例题；这些摘要不等于可用题面，仍须核对选项、答案和共享材料。

北京题源优先：目录页列出 2008–2023 年 18 套北京行测卷（含区级/乡镇等不同卷）；2023 年 PDF 和 Aipta 题页能用于定位多模块题目，但都明确存在缺题，因此不能直接当完整套卷。

跨省方面，NC513 目录页列出安徽、福建、甘肃、广东、广西、贵州、河北、海南和国考等 200 余条历年卷/模拟卷目录项；这是第三方目录数量，未做跨省联考去重。该页将“海南”题目放在“河南”标题下，已按具体卷名整理，未将其误记为河南。另整理了浙江 2026/2025/2024/2023 A/B/C 类回忆卷入口、上海已有科学推理来源中的整卷入口，以及江苏 2025 A/B/C 类回忆卷和展鸿 2025 浙江 A/B/C 三套模拟卷。浙江 2026 A/C 类公开回忆题面可定位六个模块；A/C 卷重复题仍按各自卷号保留，导入随机模块题库时应去重，整卷则继续按原卷顺序使用。

第三方模拟入口包括展鸿/32 学苑浙江卷、华图 2025 省考万人模考、NC513 2026 国考模考系列，以及江苏省考模拟卷目录；展鸿 A 类卷已定位常识、言语、数量、判断推理和资料分析样题，答案解析在同一 PDF。登录、会员或只见目录的材料已列待核，不计为可直接发布的题量。

## 知识点优先级

科学推理已有 128 个知识点、79 个完整讲解和 259 道练习题；`science-knowledge-practice-map.csv` 只导出稳定知识点 ID 与练习 ID 的关系，来源材料仍以 `src/science/` 和 `docs/science-reasoning/` 为准。本批不新增科学推理原创题。

常识判断按北京市 2026 年官方大纲列出的范围，先从北京 2023 回忆题及官方例题定位的考点整理 17 个讲解主题，覆盖经济、治理、法律、文化和科学技术。每个主题映射到可追溯题目；答题依据未核完或题面/图示不全的记录会标成候选，不进入正式训练或随机模考。其他模块暂缓新增知识点讲解。

## 当前题库衔接

当前远端主线已有科学推理题库及来源表（题量统计见 `src/science/questionBank.js` 与 `docs/science-reasoning/03_source_catalog.md`）。这里不重复复制科学题，也不写入其他模块；后续按接口要求统一迁移跨模块题目，并保留原卷关系。
